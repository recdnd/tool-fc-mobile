# fc-mobile

🌕 Device-local quick-fill for phone forms. Tap a row to copy → paste in the target app.

**Live:** https://fc.rec.ooo/

Data stays in the browser `localStorage`. Import a `.json` seed via the 📥 button (see `example.json`). No accounts, no server.

Source of truth (private): `PD+FC/fc-mobile/` inside util-PD-FC. This repo is the **public deploy mirror** only.
